# Hello Again! C++?

## Overview

Let's start a review on the [Learn C++ by Example](https://www.amazon.com/Learn-Example-Covers-versions-Bookcamp/dp/1633438333) by Frances Buontempo to learn more about C++.

As you know, C++ remains as the *invisible foundation of everything* and learn more from it can help you in your software career.

C++ is an evolution of C that aims to avoid the usage of depth of pointers, memory allocation, among others. So, C++ is no longer C with classes as it can go deeper.

C++ can be used from Operating System (SO) and embedded code to video games engines, even to Graphical User Interfaces (GUI).

Another important aspect of C++ is that it is multi-paradigm, as it can be object-oriented programming, low-level procedural, template meta-programming, or more.

Execute the codes [L01_hello_again](/learn_cpp_by_example/M01_hello_again_cpp/L01_hello_again.cpp), [L02_adding_nums](/learn_cpp_by_example/M01_hello_again_cpp/L02_adding_nums) and [L03_overview_tem](/learn_cpp_by_example/M01_hello_again_cpp/L03_overview_tem.cpp) and let's start this journey on the next module.

What will you learn? It will review topics like:

- Ranges
- Random numbers
- Vectors
- Chrono lib
- Coroutines

- Among others
